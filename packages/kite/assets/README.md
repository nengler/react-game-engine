# Assets

Everything here was made for this repository by `packages/kite/tools/make-assets.ts` (`npm run kite:assets`), in code, with no
source material from anywhere else; it is released with the repository. To change an asset, change the script and run it.

| File | What it is |
| --- | --- |
| `tiles.png` | 80 × 20, sixteen 10 × 10 tiles: stone, stone with a lit top, four spikes, three marker tiles (empty) |
| `hero.png` | 96 × 24, 12 × 12 frames of the character: idle, run, jump, fall, wall, dash, death burst |
| `font.png` | 80 × 48, a 5 × 7 pixel font in 5 × 8 cells, the characters 32 to 127 (lower case is the upper-case glyph) |
| `jump.wav` `dash.wav` `land.wav` `death.wav` `gem.wav` `start.wav` | synthesised effects (22.05 kHz, mono) |
| `theme.wav` | a 16-second looping tune, synthesised: square-wave bass and lead on an A minor pentatonic scale at 96 BPM (16 kHz, mono) |
