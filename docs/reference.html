tseAuthoring guide and reference

Built-in elements

Built-ins are capitalised. Required props are marked required.

Error codes

Codes are stable and never renumbered.

Gotchas and tips

  • If nothing moves, check that you multiplied by dt and that the component is mounted.
  • A change to a list item through another name is refused (const e = s.list[0]; e.hp = 0, or a loop variable). Write through the field (s.list[0].hp = 0), or give it a new list: s.list = s.list.map(…). s.list.push(x) itself is fine.
  • A callback under {s.x !== null && …} does not narrow s.x. Take const x = s.x above it and read x: TypeScript keeps a const's narrowing in a closure.
  • <Game> settings are literals (width={640}, never state), and <Game> is only ever a root.
  • <Text> takes its words as children (Score: {score}). A text= attribute is an error (TSE1203), and the editor's quick fix moves it into the children.
  • If a collider never fires, check both sides: each one's hits must allow the other's layer, and neither may be in a <Hud>.
  • For sharp pixel art, keep smooth off and use Screen fit="integer".
  • F11 or Alt + Enter goes full screen; fullscreenKey={false} disables F11.
  • An effect store does nothing until you mount its <ParticleLayer>, next to the Camera rather than inside it.
  • Changing an imported constant while the game runs updates nothing on screen: no component re-renders for it. Use useGame for a value that changes.
  • To debug a hitbox, put a translucent Shape of the same size beside it.
