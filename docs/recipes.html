Recipes

Short components for things most games need, each complete and ready to copy into src/. Every one is compiled and type-checked by the engine's tests, so they work with the engine as it is. For a whole starting point, rge create my-game --template menu (a title, settings and a pause menu) or --template platformer (running and jumping on solid blocks).

A menu

A title or pause menu: buttons the arrow keys (or the d-pad) move between, Enter (or A) presses, and Escape closes. <Menu> keeps the focus among its own items and goes round at the ends; autoFocus says where it starts.

import { Button, Menu, Text } from "@rge/runtime/jsx";

interface PauseMenuProps {
  onResume: () => void;
  onQuit: () => void;
}

export function PauseMenu({ onResume, onQuit }: PauseMenuProps) {
  return (
    <Menu gap={4} width={140} alignItems="stretch" onBack={onResume}>
      <Button autoFocus onPress={onResume}>
        <Text>Resume</Text>
      </Button>
      <Button onPress={onQuit}>
        <Text>Quit to title</Text>
      </Button>
    </Menu>
  );
}

Any Flex prop restyles a button: background, focusBackground, pressedBackground, or a nine-slice backgroundImage.

A settings screen

Rows that change a value in place: onAdjust hears left and right while a row has the focus, and the focus stays. A <Slider> and a <Toggle> do the same with the mouse.

import { Button, Flex, Menu, Slider, Text, Toggle, useMutable } from "@rge/runtime/jsx";

export function Options({ onClose }: { onClose: () => void }) {
  const s = useMutable({ volume: 8, shake: true });
  return (
    <Menu gap={4} width={200} alignItems="stretch" onBack={onClose}>
      <Button autoFocus onAdjust={(d) => { s.volume = Math.min(10, Math.max(0, s.volume + d)); }}>
        <Text>{`Volume < ${s.volume} >`}</Text>
      </Button>
      <Flex direction="row" gap={8} alignItems="center">
        <Text>Volume</Text>
        <Slider width={100} min={0} max={10} step={1} value={s.volume} onChange={(v) => { s.volume = v; }} />
      </Flex>
      <Flex direction="row" gap={8} alignItems="center">
        <Text>Screen shake</Text>
        <Toggle checked={s.shake} onChange={(on) => { s.shake = on; }} />
      </Flex>
      <Button onPress={onClose}>
        <Text>Back</Text>
      </Button>
    </Menu>
  );
}

Keep settings that outlive a run in a createSettings store and read them with useStore (see Systems, saved data).

A health bar

A bar is a box inside a box: the inner one's width follows the value. It renders again only when hp or max change.

import { Flex } from "@rge/runtime/jsx";

interface HealthBarProps {
  hp: number;
  max: number;
  width?: number;
}

export function HealthBar({ hp, max, width = 40 }: HealthBarProps) {
  const filled = Math.max(0, Math.min(1, hp / max)) * width;
  return (
    <Flex width={width} height={5} background="#3a1418" borderRadius={2}>
      <Flex width={filled} height={5} background={hp * 3 < max ? "#e5534b" : "#57c26b"} borderRadius={2} />
    </Flex>
  );
}

Put it in a <Hud> to keep it on the screen while the camera moves, or under an enemy to follow it.

Things that come and go

A list in state, one component per item, each with a key. A new item mounts its component; an item that leaves the list unmounts it. The item says it is done through a callback, as a React child tells its parent.

import { Entity, Shape, useMutable, useUpdate } from "@rge/runtime/jsx";

interface Spark {
  id: number;
  x: number;
}

function Fading({ x, onGone }: { x: number; onGone: () => void }) {
  const s = useMutable({ life: 1 });
  useUpdate((dt) => {
    s.life -= dt;
    if (s.life <= 0) onGone();
  });
  return <Shape kind="rect" x={x} y={80 - s.life * 40} width={4} height={4} color="gold" />;
}

export function Spawner() {
  const s = useMutable({ sparks: [] as Spark[], next: 0, timer: 0 });
  useUpdate((dt) => {
    s.timer -= dt;
    if (s.timer <= 0) {
      s.timer = 0.25;
      s.sparks.push({ id: s.next, x: (s.next * 37) % 300 });
      s.next += 1;
    }
  });
  return (
    <Entity>
      {s.sparks.map((spark) => (
        <Fading key={spark.id} x={spark.x} onGone={() => { s.sparks = s.sparks.filter((p) => p.id !== spark.id); }} />
      ))}
    </Entity>
  );
}

s.sparks.push(…) is written in place and the compiler turns it into a new list, so everything that reads it sees the change. A helper in a .ts file returns a new list instead.

A panel that takes children

A reusable panel with a title and a footer of its own, and whatever the parent passes in between: single elements, conditions and a list, each kept in its place.

import { type Child, Flex, Text } from "@rge/runtime/jsx";

interface CardProps {
  title: string;
  children: Child;
}

export function Card({ title, children }: CardProps) {
  return (
    <Flex direction="column" gap={3} padding={6} background="#1c2235" borderRadius={3}>
      <Text color="#f2d17a">{title}</Text>
      {children}
      <Text color="#7b8794">Esc to close</Text>
    </Flex>
  );
}

interface Item {
  id: string;
  name: string;
  count: number;
}

export function Bag({ items }: { items: readonly Item[] }) {
  return (
    <Card title="Bag">
      <Text>{`${items.length} kinds`}</Text>
      {items.map((item) => (
        <Text key={item.id}>{`${item.name} x${item.count}`}</Text>
      ))}
    </Card>
  );
}

A component that builds on Card may pass its own {children} on to it, between children of its own.

Picking things up

Colliders report when they start touching; the handler reads the other collider's tag (and owner, and data). There is no physics: what touching does is up to the handler.

import { Collider, Entity, Shape, useMutable } from "@rge/runtime/jsx";

export function Coin({ x, y, onTaken }: { x: number; y: number; onTaken: () => void }) {
  return (
    <Entity x={x} y={y}>
      <Shape kind="circle" width={8} height={8} color="gold" />
      <Collider width={8} height={8} tag="coin" onCollisionEnter={(other) => { if (other.tag === "player") onTaken(); }} />
    </Entity>
  );
}

export function Field() {
  const s = useMutable({ taken: 0, coins: [{ id: 1, x: 40 }, { id: 2, x: 80 }] });
  return (
    <Entity>
      {s.coins.map((coin) => (
        <Coin key={coin.id} x={coin.x} y={100} onTaken={() => { s.taken += 1; s.coins = s.coins.filter((c) => c.id !== coin.id); }} />
      ))}
    </Entity>
  );
}

To carry a value with the collision (a coin's worth, an enemy's damage), give the collider data and declare what each tag carries once in a .ts file (Systems, collisions).

A cooldown and a flash

Time is counted in the update, in seconds of game time: it follows the fixed step, replays the same, and stops while the game is paused. after and every do the same for a one-off delay.

import { after, Shape, useInput, useMutable, useUpdate } from "@rge/runtime/jsx";

export function Turret() {
  const s = useMutable({ cooldown: 0, flash: false, shots: 0 });
  useUpdate((dt) => {
    s.cooldown = Math.max(0, s.cooldown - dt);
  });
  useInput((input) => {
    if (input.pressed("Z") && s.cooldown === 0) {
      s.cooldown = 0.5;
      s.shots += 1;
      s.flash = true;
      after(0.1, () => { s.flash = false; });
    }
  });
  return <Shape kind="rect" width={12} height={12} color={s.flash ? "white" : "#57c26b"} />;
}

A press is something that happens once, so it goes in useInput; anything over time goes in useUpdate.
